Rayman Revolution EE compiler reference
=======================================

Toolchain used by this project
------------------------------

Compiler driver:
  toolchain\sn-prodg-24\local\sce\ee\gcc\bin\ee-gcc.exe

Version reported by the installed executable:
  2.9-ee-991111b/r4

Target:
  ee (Emotion Engine / MIPS R5900)

This is an old SN Systems GCC-based toolchain. Modern GCC help switches such
as --help=optimizers are not supported. The option lists below were assembled
from this installed driver's -v --help output and the bundled SDK Compiler.html.
The compiler itself notes that some language and target-specific options are
undocumented, so this documents the common C/compiler options and the
documented/help-reported target and tool options, not every private switch.

To query the installed tools again from the repository root:
  toolchain\sn-prodg-24\local\sce\ee\gcc\bin\ee-gcc.exe --version
  toolchain\sn-prodg-24\local\sce\ee\gcc\bin\ee-gcc.exe --help
  toolchain\sn-prodg-24\local\sce\ee\gcc\bin\ee-gcc.exe -v --help
  toolchain\sn-prodg-24\local\sce\ee\gcc\bin\ee-gcc.exe -dumpspecs

The -v --help command also prints the subordinate assembler and linker help.

Project defaults and matching notes
-----------------------------------

The playground and project build use these common compiler flags:
  -G4 -Iinclude -Isrc -Wa,-I,include,-I,.

-G4 places global/static objects of up to 4 bytes in small-data sections for
  access through the global pointer ($gp). It is not a debug flag. The value
  should generally be consistent across project modules. For an isolated
  playground experiment, a later -G0 can override -G4, but code that accesses
  small globals may no longer match retail.
-Iinclude and -Isrc add project header search paths.
-Wa,... forwards the comma-separated options to the assembler. Here it adds
  include\ and the repository root to the assembler's .include search path.
-fno-omit-frame-pointer is available in the playground's Preserve frame
  pointer checkbox.
-O0, -O1, -O2, and -O3 are the optimization levels accepted by the project
  build-profile parser. The playground's Other flags box can pass additional
  compiler options; per-function playground settings do not change project
  build flags.

The playground comparison is byte-for-byte. Changing a compiler option can
change code generation, data placement, ABI assumptions, or floating-point
behavior and therefore affect matching. Prefer testing one option at a time.
Do not pass options that change output mode or output filenames to the
playground.

Optimization levels
-------------------

-O0        Compiler optimization level zero. The assembler's own -O0 is a
           separate option which disables assembler NOP removal and branch
           swapping.
-O1        Basic compiler optimization. Exact pass selection is compiler
           version-specific.
-O2        Higher compiler optimization; this is the project's default.
-O3        More aggressive optimization. The SDK guide specifically notes
           additional inlining of eligible small/single-call functions.
-Os        Optimize for code size rather than speed. Supported by the compiler
           help, but not accepted by the project's build-profile parser.

The compiler accepts -O[number]. Avoid assuming modern GCC's precise pass set
or behavior applies to this GCC 2.9 EE build.

Compiler optimization and code-generation options
--------------------------------------------------

Common-subexpression and code motion:
  -fgcse                    Perform global common-subexpression elimination.
  -fedge-lcm                Use edge-based LCM with global CSE.
  -fedge-lm                 Perform edge-based load motion after global CSE.
  -fedge-sm                 Perform edge-based store motion after global CSE.
  -fno-edge-lcm             SDK EE switch: disable the new edge-based GCSE,
                            load-motion, and store-motion optimization work.
  -fno-edge-lm              SDK EE switch: disable edge-based load motion only.
  -fno-edge-sm              SDK EE switch: disable edge-based store motion only.
  -fcse-follow-jumps        Let CSE follow jumps to their targets.
  -fcse-skip-blocks         Let CSE follow conditional jumps.
  -frerun-cse-after-loop    Run CSE again after loop optimization.

Loops, branches, and instruction scheduling:
  -fstrength-reduce         Apply strength-reduction optimizations.
  -freduce-all-givs         Strength-reduce all general loop induction vars.
  -fmove-all-movables       Force loop-invariant computations out of loops.
  -funroll-loops            Unroll loops when the iteration count is known.
  -funroll-all-loops        Unroll all loops.
  -frerun-loop-opt          Run loop optimization twice.
  -fthread-jumps             Apply jump-threading optimizations.
  -fdelayed-branch           Try to fill branch delay slots.
  -fbranch-count-reg         Replace add/compare/branch patterns with a
                            branch-on-count-register sequence when possible.
  -fschedule-insns           Reschedule instructions to avoid pipeline stalls.
  -fschedule-insns2          Run two instruction-scheduling passes.
  -fsched-interblock         Schedule instructions across basic blocks.
  -fsched-spec               Allow speculative motion of non-load instructions.
  -fsched-spec-load           Allow some speculative load motion.
  -fsched-spec-load-dangerous Allow more speculative load motion.
  -fexpensive-optimizations  Enable a set of additional, potentially expensive
                            optimizations.
  -foptimize-comparisons     Apply comparison-sequence optimizations.

Inlining, registers, and addressing:
  -finline                   Honor the C inline keyword.
  -finline-functions         Inline eligible simple functions into callers.
  -fkeep-inline-functions    Emit functions even when all calls were inlined.
  -fkeep-static-consts       Emit unused static const variables.
  -fcaller-saves             Allow saving registers around calls.
  -fcall-used-REG             Treat REG as call-clobbered.
  -fcall-saved-REG            Treat REG as preserved across calls.
  -ffixed-REG                 Reserve REG so the compiler does not use it.
  -fregmove                  Enable register-move optimization.
  -foptimize-register-move   Run the full register-move optimization pass.
  -ffunction-cse             Allow function addresses to be held in registers.
  -fforce-addr               Copy address constants into registers first.
  -fforce-mem                Copy memory operands into registers first.
  -fomit-frame-pointer       Omit stack frames when possible.
  -fdefer-pop                Defer popping function arguments until later.
  -fpeephole                 Enable machine-specific peephole optimization.
  -fpeephole2                Enable a later RTL peephole pass before sched2.

Floating point, aliasing, and memory:
  -ffast-math                Optimize floating point more aggressively by
                            relaxing ANSI/IEEE behavior assumptions.
  -ffloat-store              Force floating-point values through memory.
  -fpretend-float            Assume host and target use the same FP format.
  -fdefault-single-float     Treat an integer as float rather than double by
                            default (as described by this compiler's help).
  -fstrict-aliasing          Assume strict aliasing rules.
  -fargument-noalias         Assume function arguments do not alias each
                            other, but may alias globals.
  -fargument-noalias-global  Assume arguments do not alias each other or
                            globals.
  -fargument-alias           Assume arguments may alias each other and globals.
  -fvolatile                 Treat memory references through pointers as
                            volatile.
  -fvolatile-global          Treat references to global data as volatile.
  -funaligned-pointers       Assume pointers may be unaligned.
  -funaligned-struct-hack    Assume structure fields may be unaligned.

Other compiler code-generation/behavior options:
  -fcommon                   Do not put uninitialized globals in the common
                            section.
  -fdata-sections            Put data items in separate sections.
  -ffunction-sections        Put each function in a separate section.
  -fshared-data              Mark data as shared rather than private.
  -fpack-struct              Pack structure members without padding holes.
  -freg-struct-return        Return short aggregates in registers.
  -fpcc-struct-return        Return short aggregates in memory.
  -fwritable-strings         Store string literals in writable data.
  -fshort-double             Give double the same size as float.
  -fshort-enums              Use the smallest integer type that fits an enum.
  -fsingle-precision-constant Treat floating constants as single precision.
  -ftrapv                    Raise exceptions for signed add/subtract/multiply
                            overflow.
  -fbranch-probabilities     Use profiling data for branch probabilities.
  -fprofile-arcs             Insert arc-based profiling instrumentation.
  -ftest-coverage            Emit data needed by gcov.
  -finstrument-functions     Insert function entry/exit profiling calls.
  -fstack-check              Insert stack checking code.
  -fcheck-memory-usage       Generate checks for memory accesses.
  -fsyntax-only              Check syntax without generating code.
  -fverbose-asm              Add explanatory comments to assembly output.
  -finhibit-size-directive   Do not emit .size directives.
  -fleading-underscore       Prefix external symbols with an underscore.
  -fprefix-function-name     Add a prefix to function names.
  -fdevstudio                Format diagnostics for DevStudio.
  -fgnu-linker               Emit GNU ld formatted global initializers.
  -fno-asm                   Do not recognize the asm keyword.
  -fno-builtin               Do not recognize built-in functions.
  -ffreestanding             Assume standard libraries and main may not exist.
  -fhosted                   Assume a normal hosted C environment.
  -fcond-mismatch            Allow differing types in the ?: operator.
  -fdollars-in-identifier    Allow $ in identifiers.
  -fno-ident                 Ignore #ident directives.
  -funsigned-bitfields       Make bitfields unsigned by default.
  -fsigned-char              Make plain char signed by default.
  -funsigned-char            Make plain char unsigned by default.
  -fallow-single-precision   Do not promote floats to double in traditional
                             mode.
  -fstats                    Display compiler statistics.
  -fno-default-inline        C++: do not implicitly inline class-body methods.
  -fexceptions               Enable exception handling.
  -fasynchronous-exceptions  Support asynchronous exceptions.
  -fsjlj-exceptions          Use setjmp/longjmp exception handling.
  -fnew-exceptions           Use the newer exception-handling model.
  -fpic                      Generate position-independent code when possible.
  -fsyntax-only              Check syntax and stop without code generation.
  -flive-range               Enable live-range splitting.
  -flive-range-scope         Create scope blocks for debug live ranges.
  -flive-range-gdb            Use GDB extensions to represent live ranges.
